# 📋 LISTA DE VERIFICACIÓN - Antes de Mostrar tu Proyecto

## ✅ Fase 1: Instalación (15 minutos)
- [ ] Descargado Godot 4.1+
- [ ] Clonado/descargado el repositorio
- [ ] Abierto el proyecto en Godot
- [ ] No hay errores rojos en la consola

## ✅ Fase 2: Sprites Mínimos (30 minutos)
- [ ] Creado imagen `michael_idle.png` (64x96px)
- [ ] Creado imagen `lobito_idle.png` (96x96px)
- [ ] Ambas guardadas con fondo transparente (PNG-32)
- [ ] Copiadas a `res://assets/sprites/`

## ✅ Fase 3: Configuración Godot (15 minutos)
- [ ] Importadas imágenes como Sprite Sheets
- [ ] Creados SpriteFrames en AnimatedSprite2D (michael)
- [ ] Creados SpriteFrames en AnimatedSprite2D (lobito)
- [ ] CollisionShape2D configurado para ambos personajes

## ✅ Fase 4: Prueba Básica (5 minutos)
- [ ] Proyecto ejecuta sin errores (F5)
- [ ] Michael se mueve con flechas
- [ ] Animación idle se reproduce
- [ ] Lobito aparece en pantalla

## ✅ Fase 5: Animaciones Adicionales (1-2 horas)
- [ ] Creado `michael_walk.png` (4-8 frames)
- [ ] Creado `lobito_walk.png` (4 frames)
- [ ] Configuradas en AnimatedSprite2D
- [ ] Michael camina cuando se mueve
- [ ] Lobito sigue a Michael

## ✅ Fase 6: Pulido (30 minutos)
- [ ] Ajustadas velocidades de animación
- [ ] Probados todos los controles
- [ ] Revisados errores en consola
- [ ] Comentado el código importante

## ✅ Fase 7: Compartir (Opcional)
- [ ] README actualizado con tu información
- [ ] Imágenes agregadas al repositorio
- [ ] Commit final: `git push`
- [ ] Compartido el link del proyecto

---

## 🎯 Tu Objetivo Final
**Un acompañante virtual 2D totalmente funcional que:**
- ✅ Se mueve con los controles
- ✅ Tiene animación de caminar
- ✅ Respira/pestañea en idle
- ✅ Es seguido por Lobito
- ✅ Se vería profesional

---

## 💡 Tips Profesionales
1. **Guarda frecuentemente** (Ctrl+S cada 5 minutos)
2. **Prueba cada animación** antes de pasar a la siguiente
3. **Ajusta velocidades** experimentando
4. **Mantén coherencia visual** entre frames
5. **Documenta cambios** en git con mensajes claros
